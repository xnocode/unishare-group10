# UniShare

Campus peer-to-peer sharing platform for students. Rent what you need for a day, share rides, and lend gear safely within your verified university network.

- **Live URL**: [https://unishare.online](https://unishare.online)
- **Deployment**: Hosted on Vercel with automatic CI/CD on push to `main`.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **UI & Styling**: React 19, Tailwind CSS v4, Lucide Icons
- **Typography**: Bricolage Grotesque & DM Sans
- **Database / ORM**: Prisma Client with SQLite (local development)

## Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the development site.
